# Macedonian Learning

A version-controlled source of truth for Kurt's ongoing Macedonian lessons.

## Files

- `macedonian_lesson_structure.md` defines lesson sequencing, difficulty, and tracker-integrity rules.
- `macedonian_vocabulary.md` records vocabulary status and dated evidence.
- `macedonian_grammar.md` records grammar progress, corrections, and priorities.
- `AGENTS.md` tells Codex how to run lessons and persist updates safely.

## Starting a lesson

Open this repository as the active workspace and ask:

> Next Macedonian lesson

Codex must read and reconcile the tracked files before beginning, teach one prompt at a time, and commit the completed lesson updates.
