# Macedonian Learning Repository Instructions

These instructions apply to every Macedonian lesson run from this repository.

## Source of truth

The repository files are authoritative:

- `macedonian_lesson_structure.md`
- `macedonian_vocabulary.md`
- `macedonian_grammar.md`

Do not substitute conversational memory for these files. Conversation history may be used only as evidence that must be reconciled into the trackers.

## Before every lesson

1. Read all three authoritative Markdown files in full.
2. Compare the latest completed lesson evidence with the reconciliation markers in both trackers.
3. If evidence is newer, missing, or inconsistent, update both trackers before teaching.
4. Re-read the updated sections and verify that both reconciliation markers agree.
5. Follow the lesson order and one-prompt-at-a-time interaction defined in `macedonian_lesson_structure.md`.

## During every lesson

- Use English for explanations and Macedonian Cyrillic as the target language.
- Include Latin transliteration for genuinely new Macedonian material.
- Never assume that `encountered` means learned or independently retrievable.
- Do not use an item marked `unverified` as prior knowledge.
- Introduce at least two genuinely new base words.
- End with the required short conversation.

## After every completed lesson

1. Update both vocabulary and grammar trackers with dated, factual evidence.
2. Record errors, corrections, independent successes, new material, and future retrieval priorities.
3. Set both `Last completed lesson reconciled` and `Last reconciliation performed` markers to the completed lesson date.
4. Record a cumulative-review date when applicable.
5. Re-read and verify both files before claiming that progress was saved.
6. Commit the tracker changes to Git with a concise dated commit message.

Never claim that a file was updated or progress was saved unless the write and verification succeeded.
